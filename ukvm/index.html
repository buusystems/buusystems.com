uKVM

Set up a PC. No monitor.

Plug in one tiny dongle. Change BIOS settings, read logs and install an OS from your own desk.

Ask about uKVM

See the setup screen.

The firmware's own screen, text or graphics, live in your browser. Type with your own keyboard.

Settings as a file.

Every BIOS setting as JSON. Compare, change and apply them. An undo file is saved first.

From bare to booted.

Start Linux in memory over the link, then write the OS straight onto the disk.

Wi-Fi or a wire.

The dongle relays over Wi-Fi. No Wi-Fi? It uses the machine's own Ethernet port or a USB cable.

Safe by default.

Read-only until you allow changes. Every message is signed, and Secure Boot keys are off-limits.

Scriptable.

Small signed eBPF programs automate the firmware. Each one is checked before it runs.

Tested on AMI Aptio machines: the Minisforum MS-01 and Beelink MINI S.
