uKVM

Every server, within reach.

One small dongle per machine gives you its BIOS, its logs, and a fresh OS install from anywhere. Built for datacenters, labs, and fleets in the field.

Ask about uKVM

The console, from anywhere.

Each machine's firmware screen, text or graphics, live in your browser. No monitor, no crash cart, no site visit.

Settings as a file.

Every BIOS setting as JSON. Compare machines, spot drift, and apply changes. An undo file is saved first.

From bare metal to booted.

Start Linux in memory over the link, then write the OS straight onto the disk. No USB stick to carry in.

No ports to open.

Each dongle dials out to your relay over Wi-Fi, the machine's own Ethernet, or USB, so it works behind firewalls and NAT.

Safe by default.

Read-only until you allow changes. Every message is signed, and Secure Boot keys are off-limits.

Automate the fleet.

Small signed eBPF programs script the firmware. Each one is checked before it runs.

Tested on AMI Aptio machines: the Minisforum MS-01 and Beelink MINI S.
